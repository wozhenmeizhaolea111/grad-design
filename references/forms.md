# 表单结构与填写说明（阶段③⑥）

来源：《咸阳职业技术学院XXXX学院毕业设计任务书（正反两面打印）》《毕业设计指导记录（正反面打印）》《咸阳职业技术学院毕业论文评分表》。
电子模板见 `templates/`（由原表转换，不要自行发明表格结构）。

## 一、毕业设计任务书

### 表头字段

| 字段 | 填写说明 |
|---|---|
| 二级学院 | 学院全称 |
| 专业 / 班级 / 学号 | 按学籍信息填 |
| 指导教师 | 姓名 |
| 毕业设计题目 | 与封面、正文、评分表**完全一致** |
| 毕业设计时间 | `____年__月__日 至 ____年__月__日` |
| 毕业设计形式 | 五选一勾选：**方案 / 物化产品 / 文化作品 / 软件 / 其他**（与选题类别匹配：作品/产品设计类→物化产品或文化作品；方案设计类→方案；软件类→软件） |

### 正文字段

**毕业设计选题目的意义及主要任务要求**

写作要点（两段式）：
1. **目的意义**：课题来源（企业真实项目/行业背景）、解决什么实际问题、符合哪条选题要求（见 `topics.md`）、对专业培养目标的支撑。
2. **主要任务要求**：分条列出学生要完成的具体任务，须与后续正文成果一一对应（完整性指标"体现任务书规定要求"即由此而来）。小组课题必须写明**每个学生的具体分工**（≤3 人）。

**计划安排（四周）**

按周填写，每行一栏，内容具体到可交付物：

| 周次 | 填写要点 |
|---|---|
| 第一周 | 选题、资料检索、需求/背景分析 |
| 第二周 | 方案论证与拟定（或创意构思、技术路线确定） |
| 第三周 | 设计/制作/实现（图纸、程序、样品、方案成文） |
| 第四周 | 测试与效果分析、说明书撰写、排版自检、答辩准备 |

> 四周计划必须与"主要任务要求"闭环，且工作量饱满。

### 表尾

- 注：本表一式三份正反面打印，二级学院、指导教师、学生各一份；二级学院审核签章后由学生将扫描件上传平台。
- 导师签字/日期、学生签字/日期、二级学院签章/日期。

## 二、毕业设计指导记录（正反面打印，每面为一张记录表）

| 字段 | 填写说明 |
|---|---|
| 姓名 / 学号 / 专业班级 / 指导教师 | 按学籍信息 |
| 选题 | 与任务书题目一致 |
| 第 N 次指导主要内容记录 | 每次一栏，按指导先后编号 |
| 教师要求 | 指导教师提出的问题与要求（教师填写/口述） |
| 学生采取的措施 | 学生针对性的改进动作，须与"教师要求"逐条呼应 |
| 学生签名 / 指导教师签名 / 年月日 | 双方签名，日期真实 |

填写原则：
- 多次记录之间要有**递进展开**（选题→方案→初稿→修改→定稿），不能雷同复制。
- 只记录真实发生的过程，**严禁伪造签名与记录**（见 SKILL.md 边界）。

## 三、毕业设计成绩评定表（评分表）

### 表头

姓名、性别、学号、专业、题目。

### 评价结构

| 评价内容 | 明细 | 评分人 |
|---|---|---|
| 过程评价（30%） | 过程参与完整性及态度 | 由指导教师打分 |
| 答辩评价（70%） | 成果评价：成果的科学性、成果的完整性、成果的规范性、成果的实用性 | 由答辩小组评分 |
| | 答辩表现：回答问题的准确性 | 由答辩小组评分 |

- 总分 100 分
- 指导教师评语及成绩栏：成绩、指导教师签字、年月日
- 注：优秀 86–100；良好 70–85；及格 60–69；不合格 59 以下。此表由指导教师填写，每名学生一份。

> 成果评价四项的打分标准即 `rubric.md` 第二/三节指标表；70% 内部细分原表未规定，不自行发明。
