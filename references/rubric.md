# 毕业设计成果质量评价指标（阶段④⑥）

来源：《附件1-8》《附件1-12》评价指标表 +《咸阳职业技术学院毕业论文评分表》。
用途：④ 写正文前把指标拆成写作清单；⑥ 成稿后按表自评打分。

---

## 一、成绩评定总表（评分表结构）

- **过程评价 30%**：过程参与完整性及态度 —— 由指导教师打分
- **答辩评价 70%**：
  - 成果评价（由答辩小组评分）：成果的科学性、成果的完整性、成果的规范性、成果的实用性
  - 答辩表现：回答问题的准确性
- 总分 100 分

**等级线**：优秀 86–100；良好 70–85；及格 60–69；不合格 59 以下。

## 四、写作前自检清单（阶段④）

把当前大类+类别的指标表转成 checklist，正文逐条落实：

- [ ] **科学性**：技术/创意方案论证充分，参数计算准确，来源引用可靠，体现新技术新工艺，满足成本环保安全
- [ ] **规范性**：结构完整、排版符合 `format.md`，图表符合国家/行业标准，参考文献引用标识准确，专业语言正确
- [ ] **完整性**：覆盖任务书全部规定要求；完整记录"分析→拟定→参数→成型→效果"全过程及过程性结论；资料要素齐备
- [ ] **实用性**：达到功能/技术指标或项目要求，可操作性强，能解决实际问题，有应用价值

## 五、自评打分模板（阶段⑥）

> 原评分表只规定 过程评价30% + 答辩评价70%，**70% 内部"成果评价"与"答辩表现"的再分配比例原表未给出**，由各答辩小组掌握，不要擅自发明具体权重。
> 成果评价打分直接套用第二/三节的百分制指标表（科学性30/规范性20/完整性30/实用性20）。

```

答辩评价（70%）：
  成果评价（答辩小组，按本文件指标表打分）：
    科学性 ___/30   规范性 ___/20   完整性 ___/30   实用性 ___/20
  答辩表现：回答问题的准确性 ___
总分（100分）：___
等级：优秀 86–100 / 良好 70–85 / 及格 60–69 / 不合格 ≤59
```
